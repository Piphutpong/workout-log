## ข้อสังเกตอื่น (ไม่ได้ติด "ตรวจสอบ")
- **ทำซ้ำ Week X** (21KM Begin D22, D29, D36 และ 21KM Performance D22-D28) เก็บเป็น `repeat_of_week`
  แอปจะดึงรายละเอียดจากวันที่ตรงกันของสัปดาห์นั้นให้อัตโนมัติ (เช่น D22 → D8) และถ้าวันไหนเขียน "บอดี้เวทหลังวิ่ง" เพิ่ม ก็จะรวม `add_weights` ด้วย
- วันที่ไม่ระบุการพักระหว่างเที่ยว (เช่น 21KM Begin D73 "T.pace 6x1k", 10KM Performance D26, D30) ไม่ได้ใส่ recovery ไว้ — Interval timer จะให้กด "ถัดไป" เอง
- Zone ใช้ %MaxHR: Z1 50-60, Z2 60-70, Z3 70-80, Z4 80-90, Z5 90-100 (แก้ได้ในไฟล์ builder)
- "พัก หรือ …" / "… หรือพัก" (10KM Performance D88, 21KM Performance D57, D67) ตั้งเป็นวันวิ่งพร้อม note "หรือพัก"
- ประเภทวันที่ใช้: Recovery run → `easy`, "5km 80-85%" / "6k 80-90%" / "8km 80-90%" → `tempo`, "T.Pace" → `threshold`, "Vo2Max" → `vo2max`
- รูปหน้าหนังสือ "ตัวอย่างโปรแกรมสำหรับกระชับกล้ามเนื้อ (นายแบบ)" ไม่ใช่ตารางวิ่ง — นำไปสร้างเป็นโปรแกรมเวท "นายแบบ 1-3" ใน Phase 2 แทน

## วิธีแก้
1. แก้ `scripts/build-run-plans.mjs`
2. `npm run plans:build && npm run seed:build`
3. รัน `supabase/seed.sql` ใหม่ (upsert ทับได้ ไม่กระทบแผนที่คัดลอกไว้หรือประวัติวิ่ง)

หรือในแอป: เปิดแผน → "คัดลอกเป็นของฉัน" → แตะวันที่ต้องการ → "แก้ไขวันนี้"
